# Security Policy

AiTECHNETWORKS LIMITED takes the security of AiTECH Manager and its distribution infrastructure seriously.

## Supported Releases

| Release | Supported |
|---|---:|
| `v1.2.0-websocket-pro.1` | Yes |
| Earlier releases | No |

Users should install the latest checksum-verified release before reporting a vulnerability.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through GitHub:

[Submit a private security report](https://github.com/Alouk0/aitech-manager-releases/security/advisories/new)

Include the affected version, Ubuntu version, impact, reproduction steps, and sanitized logs when available.

Do not publish vulnerability details in GitHub Issues, Discussions, social media, or Telegram.

Never include licence keys, passwords, private keys, tokens, server credentials, or customer information in a report.

We aim to acknowledge complete reports within three business days and will coordinate remediation and responsible disclosure when appropriate.
